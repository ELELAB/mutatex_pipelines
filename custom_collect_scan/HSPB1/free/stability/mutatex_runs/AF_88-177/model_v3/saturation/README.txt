The current filetree was generated by running the following Snakemake pipeline:
                        
/data/user/albertopettenella/collect_scan_update
                        
The scan folder hosts a custom scanning run performed with MutateX and the table folder
collects in a .csv file the predicted changes in folding free energy upon mutation for each protein residue.
                        
The following files were provided as input to perform the scan with MutateX:
- HSPB1/free/stability/mutatex_runs/AF_88-177/model_v3/saturation/mutate_runfile.txt
- HSPB1/free/stability/mutatex_runs/AF_88-177/model_v3/saturation/repair_runfile.txt
- HSPB1/free/stability/mutatex_runs/AF_88-177/model_v3/saturation/mutation_list.txt
The input .pdb file can be found in the folder:
HSPB1/free/structure_selection/AF
                        
The pipeline can be summarized as follows:
1. Generate input .txt files and create a consistent input directory structure
2. Copy, if provided by the user, or download from AF Protein Structure method, the .pdb file 
from HSPB1/structure_selection into HSPB1/free/stability/mutatex_runs/AF_88-177/model_v3/saturation
3. Trim the .pdb file by using pdb_selres tool to consider only the user-specified residues if required by the user 
4. Run MutateX and generate a consistent output directory structure
5. Collect resulting energies in a .csv file
